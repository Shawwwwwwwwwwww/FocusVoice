# Bundled sounds

All WAV/CAF/AIFF files in this directory are original synthesized tones created for FocusVoice
and are covered by the repository's MIT license. The historical names `开始录音` / `结束录音` /
`Siri 唤醒` / `iMessage 已发送` are kept only as stable identifiers for older preference values;
they do not contain Apple system audio.

At runtime the app may optionally read system sound files already installed on the user's Mac.
Those files are never redistributed in this repository.
