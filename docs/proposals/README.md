## 二、蓄力环：与音效同步的两套方案

| 方案 | 预览 | 逻辑 |
|---|---|---|
| **A · 双脉冲（推荐搭 Siri 唤醒）** | `ring-A-双脉冲.png` | 线条先慢后快画满；在开始音的两个音符时刻，线上各亮一小段白光，最后在 0.6s 收尾扫光 |
| **B · 呼吸线（推荐搭原生录音）** | `ring-B-呼吸线.png` | 线条 + 笔尖匀速（先慢后快）；中段整条线轻微"呼吸"变亮一次，最后扫光 |

两套都保持：96pt 大画布、纯线条、无填充面、蓄满只在线条上闪。

## 三、菜单栏：录音态

`menubar-states.png`：

- **空闲**：模板单色圆环 + 中心点（跟随明暗自动反色）。
- **录音中**：同一圆环 + **红色录制点**（非模板，保持红色），约 0.8s 呼吸一次；结束立即恢复空闲。
- 可选：转写中显示蓝色点，失败闪橙色点（如需要可加）。

## 四、App 图标

`icon-options.png`：

| 方案 | 说明 |
|---|---|
| **A · 暗色光环（当前已安装）** | 与 HUD/蓄力环同一套视觉语言，最统一 |
